## 5. Features Not Captured or Planned for Future Phases (Phase 10 Scope)

In compliance with hackathon evaluation ethics and transparency requirements, the following features are explicitly noted:

1. **Digital Payment Escrow (UPI / Razorpay / PayPal):**
   - **Current Status:** Not captured in current screenshots because direct payment processing is scheduled for **Phase 10** in the roadmap (`README.md`).
   - **Why:** The core mission in Phases 1–9 is connecting farmers and workers directly, establishing transparent wages without middleman cuts, and providing location-based discovery. No mock or simulated payment checkouts were added to maintain honesty.
2. **External Cloud Large Language Models (OpenAI GPT-4 / Google Gemini API):**
   - **Current Status:** Not required or invoked by the application.
   - **Why:** AgriConnect's intelligent matching, wage benchmarks, and labor demand forecasts are powered by deterministic Node.js algorithms (`aiService.js`), Haversine trigonometric distance formulas, and localized agricultural wage tables. Voice recognition uses the browser's native Web Speech API (`SpeechRecognition` & `SpeechSynthesis`). Cloud LLM API integration is planned as an optional advisory layer in Phase 10.
3. **SMS / GSM Telecom Gateway:**
   - Phone numbers are validated in the UI and stored for verified contacts; SMS OTP dispatch is planned for carrier integration in future rural deployments.
