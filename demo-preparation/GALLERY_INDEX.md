## 4. Hackathon Technical Evaluation & Honest Disclosure

In accordance with strict hackathon presentation standards, AgriConnect distinguishes between implemented production systems and planned future scope:

### 1. PayPal / UPI Payment Gateway Status
- **Current Status:** **Planned for Phase 10 (Not in Current Submission).**
- **Transparency Statement:** There is no fake checkout or simulated PayPal modal in these gallery screenshots. Payment processing is documented in `README.md` under Future Scope (Phase 10: UPI Escrow & Direct Labor Payouts). The current platform focuses on transparent wage agreements, direct discovery, and verified hiring.

### 2. AI / Smart Matching Architecture
- **Current Status:** **Algorithmic Heuristics & Geolocation Math (No External LLM API).**
- **Transparency Statement:** The system uses custom mathematical algorithms implemented in Node.js (`aiService.js`):
  1. **Haversine Geolocation Engine:** Great-circle trigonometric formula computing exact worker-to-farm distance in kilometers.
  2. **Multi-Parameter Fit Scoring:** Heuristic compatibility scoring (crop expertise, proximity, wage parity) returning 60%–99% match scores.
  3. **Wage Parity Guidance:** District-level benchmark lookup for agricultural operations.
  4. **Voice Assistance:** Web Speech Recognition (`SpeechRecognition`) and SpeechSynthesis API for regional voice interaction.
  No external closed-source LLM API keys (OpenAI, Gemini) are required to run the core application.
